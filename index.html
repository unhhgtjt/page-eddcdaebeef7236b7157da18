Procedure & Setup

客户端接入规程

翻云梯采用标准化通用协议接口分发网络节点配置，请遵循以下四步完成接入。

01 / SUBSCRIBE

获取分发订阅链接

完成方案选择后，系统控制台将生成专属订阅 URL。该 URL 包含经过编码的节点清单及证书公钥，请妥善保存并避免外泄。

02 / COMPLIANCE

配置环境核对

确认本地设备的系统时钟同步处于毫秒级误差内。网络代理协议对时间戳握手有严格校验，时钟偏移可能导致握手中断。

03 / PARSE

载入节点至解析端

在支持对应协议的第三方或通用客户端中添加 Remote Subscription，粘贴翻云梯订阅地址，触发拉取并完成节点解析。

04 / ROUTING

应用流量分流规则

选用规则路由模式（Rule-based Routing），确保本地局域网与国内直连请求免走隧道，实现网络传输的分流优化。

Platforms & Protocols

终端平台与兼容说明

翻云梯基于业界开源协议标准传输，不强制绑定专有运行环境，各主流系统均可通过兼容工具进行配置。

Windows 环境 WIN64

支持通过通用规则客户端加载翻云梯订阅源。具备系统级代理托管与 TUN 虚拟网卡两种接管模式，适用于桌面全局或进程代理。

兼容协议：Shadowsocks / Trojan / VMess

macOS 与 iOS 环境 DARWIN

支持基于 NetworkExtension 框架的通用解析工具。在 iOS 设备上通过扫码即可同步节点资产，macOS 下支持规则热重载。

兼容协议：Shadowsocks / Trojan / Vless

Linux 与 Android 环境 POSIX

Frequently Asked Questions

常见问题排查与技术释疑

针对连接认证、配额计算与路由分发等典型运行状态的说明汇总。

翻云梯的配额重置周期如何计算？

数据传输配额按账单周期进行自然更新。例如账单日起始于每月 15 日，则在下月 15 日 00:00 自动重置已用流量统计，未消耗的流量不结转至下一周期。

多设备同时在线的判定机制是什么？

系统服务端按当前正在保持 TCP 活跃长连接或处于有效会话窗口内的唯一公网 IP 与客户端标识符组合进行计数。超出套餐对应设备上限后，新发起的连接请求将被限流或等待排队。

遇到节点不可达或连接超时时应如何检查？

首先请检查客户端本地时钟是否与标准网络时间一致；其次，确认订阅链接是否已在客户端内执行“更新订阅”以同步最新的服务器地址与端口；最后，请排查本地防火墙是否拦截了出站代理端口。

旗舰版专线与普通节点的技术区别为何？

旗舰版与团队版所使用的 IPLC 专线依托局域点对点内部通道传输数据，不经过公网国际出口链路，因而在国际公网拥堵时段仍能保持抖动率与丢包率处于较低区间。

是否可以根据业务需要定制专属路由规则？

团队版用户可通过系统后台配置特定私有 IP 范围或特定企业域名的解析分流策略。基础版与旗舰版则使用系统统一发布的标准分流规则列表。

订阅地址被污染或泄露后如何处理？

用户可在翻云梯管理面板中选择重置订阅令牌（Token）。重置后旧订阅 URL 立即失效，节点认证密钥同步更换，需在客户端中重新导入新链接。
